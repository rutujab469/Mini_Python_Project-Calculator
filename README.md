
# Mini Python Project - Calculator 🧮

A simple calculator project built using **Python**. This project performs basic arithmetic operations by taking input from the user.

## 📌 Project Overview

This is a beginner-friendly Python calculator that allows the user to select an operation and enter two numbers. The program then performs the selected operation and displays the result.

## ✨ Operations

The calculator supports the following operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Average

## 🛠️ Technologies Used

* Python 3
* Functions
* Conditional Statements
* User Input
* Arithmetic Operators

## ⚙️ How It Works

The calculator is built in three main steps:

### Step 1: Create Functions

Separate functions are created for each operation:

* `add()` → Addition
* `sub()` → Subtraction
* `multiply()` → Multiplication
* `divide()` → Division
* `avg()` → Average

### Step 2: Take User Input

The program asks the user to:

* Select an operation
* Enter the first number
* Enter the second number

### Step 3: Display the Result

Based on the selected operation, the program calls the appropriate function and displays the result.
